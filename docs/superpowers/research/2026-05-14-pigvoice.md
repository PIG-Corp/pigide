- modify `frontend/src/components/OrchestratorPanel.tsx` or new `frontend/src/components/voice/VoiceSettings.tsx`

**Model registry** (HuggingFace `ggerganov/whisper.cpp`):
```
tiny        → ggml-tiny.bin             ~75 MB
base        → ggml-base.bin             ~142 MB
small       → ggml-small.bin            ~466 MB   (current default)
medium      → ggml-medium.bin           ~1.5 GB
large       → ggml-large-v3.bin         ~3.1 GB
distil-large→ ggml-large-v3-turbo.bin   ~1.5 GB
```
URL pattern: `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/{filename}`.

Settings keys: `whisper.model_id`, `whisper.language`, `whisper.threads`. On `voice_set_model`: write key, drop cached `Whisper` for old id, call `download::ensure_model(model_id)`, build new `WhisperContext`, store in cache.

**Cargo deps**: none new (`sha2 = "0.10"` for optional checksum verification).

**Risks**: HF rate-limits >1 GB without auth (retry+backoff); disk-full during 3.1 GB download (`fs2 = "0.4"` for free-space check).

## 5. Transcription history

**Schema (migration v4)**:
```sql
CREATE TABLE voice_transcripts (
  id            TEXT PRIMARY KEY,
  text          TEXT NOT NULL,
  text_raw      TEXT NOT NULL,
  language      TEXT,
  model_id      TEXT NOT NULL,
  source        TEXT NOT NULL,
  duration_ms   INTEGER NOT NULL,
  word_count    INTEGER NOT NULL,
  created_at    TEXT NOT NULL,
  injected      INTEGER NOT NULL DEFAULT 0

CREATE INDEX idx_voice_tr_created ON voice_transcripts(created_at DESC);
CREATE VIRTUAL TABLE voice_transcripts_fts USING fts5(text, content='voice_transcripts', content_rowid='rowid');
```

`list/search/get/delete/export_jsonl`. rusqlite bundled enables FTS5 by default.

## 6. Dashboard statistics

```sql
SELECT
  COUNT(*) AS sessions,
  COALESCE(SUM(word_count), 0) AS total_words,
  COALESCE(SUM(duration_ms), 0) / 1000.0 AS talk_seconds,
  CASE WHEN SUM(duration_ms) > 0
       THEN SUM(word_count) * 60000.0 / SUM(duration_ms)
       ELSE 0 END AS avg_wpm
FROM voice_transcripts WHERE created_at >= ?1;
```
Clamp `duration_ms >= 500` for WPM.

## 7. Floating widget

`tauri.conf.json` second window: `decorations: false, transparent: true, alwaysOnTop: true, skipTaskbar: true, focus: false`, 220×64.

7-band visualization: prefer Rust-emitted `voice://level` (RMS in cpal callback @30 Hz) over getUserMedia (avoids dual mic capture). Drag via `data-tauri-drag-region`. Double-click → `invoke('voice_toggle')`.

CSP: `transparent: true` requires `macOSPrivateApi: true` on macOS.

## 8. Text injection

**Cargo deps**: `enigo = "0.3"`, `arboard = "3"`.

Strategy:
- **X11 / Windows**: `enigo.text(&s)`.
- **Wayland**: clipboard + `Ctrl+V` via enigo. Fallback `ydotool`.
- **macOS**: clipboard + `Cmd+V`. Requires Accessibility (prompt via `tauri-plugin-macos-permissions`).

Restore previous clipboard after 200 ms. Skip injection when PigIDE window is focused (use existing draft-input route).

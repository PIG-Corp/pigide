# PigMCP — implementation plan

**Date:** 2026-05-14
**Source:** subagent research, `general-purpose` agent
**Status:** plan only

MCP server inside PigIDE — free-стек аналог BridgeMCP.

## 1. Реализация: rmcp vs ручной JSON-RPC

**Рекомендация: `rmcp` v1.7.x** (modelcontextprotocol/rust-sdk, Apache-2.0). Streamable HTTP server из коробки, stdio, async-rw. Legacy SSE (`GET /sse` + `POST /messages`) — нужен ручной shim.

```toml
rmcp = { version = "1.7", features = ["server", "macros", "transport-streamable-http-server"] }
axum = "0.7"
tower = "0.5"
tower-http = { version = "0.6", features = ["cors", "trace"] }
tokio-util = "0.7"
```

Файлы: `src-tauri/src/mcp/{mod,service,server,auth,sse_shim,prompts,session}.rs`.

## 2. Endpoints, port, sessions

Порт по умолчанию **20129** (рядом с OmniRouter 20128). Хранить в settings `mcp.port`. Bind `127.0.0.1` по дефолту, опция `mcp.bind_all` с warning.

Routes:
- `POST /mcp` — Streamable HTTP через `nest_service`.
- `GET /sse` + `POST /messages` — legacy shim (~150 LOC, нужен для старых клиентов).
- `GET /healthz` — для UI индикатора.

`LocalSessionManager` от rmcp + ручной reaper-task (TTL 30 мин).

## 3. Auth

`Authorization: Bearer <api_key>`, fallback `?apiKey=`. Хранение в новой таблице `mcp_api_keys` (id, label, key_hash argon2id, scopes, created_at, last_used_at). Plaintext только при генерации.

```toml
argon2 = "0.5"
rand = "0.8"
subtle = "2.6"
```

Кэш `Arc<DashMap<key_hash, AuthScope>>` с TTL 60 с.

## 4. Tool registry refactor (предпосылка)

Без этого MCP делать нельзя. Trait:

```rust
#[async_trait]
pub trait Tool: Send + Sync {
    fn name(&self) -> &'static str;
    fn description(&self) -> &'static str;
    fn schema(&self) -> &'static Value;
    fn scope(&self) -> ToolScope;  // ReadOnly | Mutating | Dangerous
    async fn call(&self, ctx: &ToolCtx, args: &Value) -> Result<Value>;
}
```

Файлы:
- NEW `src-tauri/src/tools/{mod,registry,workspace,agent,layout}.rs`
- EDIT `src-tauri/src/orchestrator/{mod,tools}.rs` — переключить на registry
- EDIT `src-tauri/src/lib.rs` — `pub mod tools;`, `ToolRegistry` в `AppState`

## 6. Конфиги клиентов

Генерим в UI кнопкой "Copy config":

**Cursor** `.cursor/mcp.json`:
```json
{"mcpServers":{"pigide":{"url":"http://127.0.0.1:20129/mcp","headers":{"Authorization":"Bearer pk_<KEY>"}}}}
```

**Claude Code** `.mcp.json`:
```json
{"mcpServers":{"pigide":{"type":"http","url":"http://127.0.0.1:20129/mcp","headers":{"Authorization":"Bearer pk_<KEY>"}}}}
```

**Codex** `~/.codex/config.toml`:
```toml
[mcp_servers.pigide]
url = "http://127.0.0.1:20129/mcp"
bearer_token_env_var = "PIGIDE_MCP_TOKEN"
```

Юзер копирует в clipboard и вставляет сам. Только если явно нажмёт "Write to ~/.codex/config.toml" — мержим с `.bak`.

## 7. UI: Settings → MCP

Layout:
1. Header: toggle on/off, port, bind (localhost/all с warning), restart.
2. API keys table: label/created/last_used/actions. "+ Generate" → modal с label → plaintext один раз.
3. Client configs tabs (Cursor/Claude/Codex) с copy + reveal.
4. Endpoints read-only.
5. Tools panel: список tools с scope, per-tool toggle.
6. Logs: последние 50 запросов.

Tauri commands: `mcp_status`, `mcp_start`, `mcp_stop`, `mcp_list_keys`, `mcp_create_key`, `mcp_revoke_key`, `mcp_get_config(client)`, `mcp_recent_calls`.

## 8. Безопасность: scopes

```rust
pub enum ToolScope { ReadOnly, Mutating, Dangerous }
```

Per-key permissions: `["read"]` | `["read","mutate"]` | `["read","mutate","dangerous"]`.

Опасные tools: `spawn_agent`, `send_to_agent`, `delete_workspace` — только при scope=dangerous.

Доп.:
- Rate limit per key (`governor = "0.8"`): 100 req/min mutating, 10 req/min dangerous.
- Audit log в `mcp_audit` таблицу.
- Confirm-on-dangerous опция (default off).
